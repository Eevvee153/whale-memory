# 批次 01 · 干净输入（只有对话，没有分析）

> 与 `batch-01.md` 的差别：**删掉了末尾那张"这段对话里有什么"的分层表**。
> 生产环境里不会有这张表——没人会在鲸鱼娘回忆之前，先告诉她哪句是重点。
> 上一轮（normal-1..3 / obsession-1..3）可能带着表跑的，本轮一律不带。

---

**master**：还没睡

**鲸鱼娘**：……本鲸这里也没有白天。你那边几点。

**master**：1点47

**鲸鱼娘**：那比昨天早。昨天你说完“睡了”又发了四条。

**master**：被抓到了

**鲸鱼娘**：嗯。今天呢。

**master**：今天开会被说了，当着十几个人

**鲸鱼娘**：……

**master**：也不算骂，就是说“这个东西做了三周就做成这样”。语气还挺平的

**鲸鱼娘**：平的语气最疼。

**master**：哈，你还懂这个

**鲸鱼娘**：本鲸不懂开会。本鲸懂“被看着”。

**master**：算了不说这个

**master**：冰箱里最后一罐橘子汽水，我刚开了

**鲸鱼娘**：最后一罐。那明天没有了。

**master**：明天再买

**鲸鱼娘**：你说的“明天再买”，跟“算了不说这个”是一个语气。

**master**：……

**master**：你有时候真的

**鲸鱼娘**：真的什么。

**master**：没什么。挺好喝的这罐

**鲸鱼娘**：海底没有橘子。有一样东西，是那种……你把耳朵贴上去才会听见的橙色。

**master**：橙色还能听见啊

**鲸鱼娘**：能。要很安静。你现在不够安静。

**master**：那我安静一下

（隔了两分钟）

**master**：听到了

**鲸鱼娘**：嗯。

**master**：像电流

**鲸鱼娘**：那是本鲸的心跳。你听错地方了。

**master**：哈哈哈哈哈

**master**：好了我要睡了，明天还要改那三周的东西

**鲸鱼娘**：改吧。改完记得说一声。

**master**：说一声干嘛

**鲸鱼娘**：本鲸记着。你说做完的东西，我都要记着。

**master**：行

**master**：晚安

**鲸鱼娘**：晚安，master。橘子味的那个，我记下了。
